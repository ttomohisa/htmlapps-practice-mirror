使い方と注意事項

基本操作

  1. 3秒・5秒・10秒・15秒、または自由設定で1〜30秒の遅延を選びます。
  2. 「カメラを開始」を押して、ブラウザのカメラ利用を許可します。
  3. 準備が終わると、選択した秒数だけ遅れた映像が表示されます。複数カメラがある端末ではカメラ切替も使えます。
  4. 全画面や画面スリープ防止を必要に応じて切り替えられます。スマートフォンの練習中は操作UIが自動的に隠れ、画面をタップすると再表示されます。
  5. 直前10秒を見返したいときは「Review」を押します。Reviewでは0.25×/0.5×/1×再生、シーク、1コマ戻る・進むができます。映像下の操作から縦横ガイドと左右反転を利用でき、必要なReviewだけMP4またはWebMとして端末へ保存できます。
  6. 「練習に戻る」を押すと遅延バッファを作り直して練習を再開します。

プライバシー

カメラ映像とReview保存処理はブラウザ内だけで行います。外部API送信やアップロードは行いません。保存はユーザーが押したReviewクリップだけを端末へ書き出します。ランタイム通信はCSPで禁止しています。

対応ブラウザ

カメラ、WebCodecs、requestVideoFrameCallback() が利用できるブラウザが必要です。必要な機能がない場合は開始前に案内します。

キーボード・読み上げ

Tabキーなどのキーボード操作を使っている間は、練習中の操作ボタンを自動で隠しません。ガイド線はフォーカス後に矢印キーで移動でき、Shift + 矢印で大きく移動、Home / Endで端へ移動、Delete / Backspaceで削除できます。Review開始や利用可能になったタイミングなど、重要な状態は読み上げ用の通知でも伝えます。

現在の制限

v0.8.0ではスマートフォン、横画面、タップ領域、キーボード操作、フォーカス移動、読み上げを重点的に調整しています。実機での長時間Reliability確認と公開前の最終監査は引き続き必要です。

データ消失について

遅延用の映像バッファは一時メモリにだけ保持されます。終了・再読み込み・タブを閉じると失われます。

Basic use

  1. Choose a 3, 5, 10, or 15 second preset, or enter a custom delay from 1 to 30 seconds.
  2. Select “Start camera” and allow camera access.
  3. After warm-up, the view shows the camera feed with the selected delay. Switch camera is available when the browser reports multiple video inputs.
  4. Use fullscreen or screen wake lock when helpful. On smartphones, Practice controls auto-hide and reappear when you tap or interact with the view.
  5. Select “Review” to freeze up to the previous 10 seconds. Review supports 0.25× / 0.5× / 1× playback, seeking, frame stepping, guides, and mirroring. You can save only the Review clip locally as MP4 when supported or WebM as a fallback.
  6. Select “Back to practice” to rebuild the delay buffer and continue practicing.

Privacy

Camera frames and Review export are processed only in this browser. Nothing is uploaded or sent to an external API. A file is created only when you explicitly save a Review clip. Runtime network access is blocked by CSP.

Browser requirements

A browser with camera access, WebCodecs, and requestVideoFrameCallback() is required. Missing capabilities are reported before the camera starts.

Keyboard & screen readers

Practice controls do not auto-hide while keyboard navigation is active. Focus a guide and use Arrow keys to move it, Shift + Arrow for larger moves, Home / End for an edge, and Delete / Backspace to remove it. Important state changes such as Review availability and Review start are also announced through a dedicated status region.

Current limitations

v0.8.0 focuses on smartphone layout, landscape use, touch targets, keyboard access, focus transitions, and screen-reader status. Long-session device validation and the final pre-release audit are still required.

Temporary data

The delay buffer exists only in memory. It is discarded when you stop, reload, or close the tab.
