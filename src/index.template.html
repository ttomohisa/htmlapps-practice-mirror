使い方と注意事項

基本操作

  1. 5秒または10秒の遅延を選びます。
  2. 「カメラを開始」を押して、ブラウザのカメラ利用を許可します。
  3. 準備が終わると、選択した秒数だけ遅れた映像が表示されます。
  4. 直前10秒を見返したいときは「Review」を押します。Reviewでは0.25×/0.5×/1×再生、シーク、1コマ戻る・進むができます。映像下の操作から縦横ガイドと左右反転を利用でき、必要なReviewだけMP4またはWebMとして端末へ保存できます。
  5. 「練習に戻る」を押すと遅延バッファを作り直して練習を再開します。

プライバシー

カメラ映像とReview保存処理はブラウザ内だけで行います。外部API送信やアップロードは行いません。保存はユーザーが押したReviewクリップだけを端末へ書き出します。ランタイム通信はCSPで禁止しています。

対応ブラウザ

カメラ、WebCodecs、requestVideoFrameCallback() が利用できるブラウザが必要です。必要な機能がない場合は開始前に案内します。

現在の制限

v0.4.0ではReviewクリップのローカル保存に対応しています。保存形式はブラウザが対応するMP4を優先し、利用できない場合はWebMを使います。カメラ切り替え、Wake Lock、全画面はまだありません。

データ消失について

遅延用の映像バッファは一時メモリにだけ保持されます。終了・再読み込み・タブを閉じると失われます。

Basic use

  1. Choose a 5 or 10 second delay.
  2. Select “Start camera” and allow camera access.
  3. After warm-up, the view shows the camera feed with the selected delay.
  4. Select “Review” to freeze up to the previous 10 seconds. Review supports 0.25× / 0.5× / 1× playback, seeking, frame stepping, guides, and mirroring. You can save only the Review clip locally as MP4 when supported or WebM as a fallback.
  5. Select “Back to practice” to rebuild the delay buffer and continue practicing.

Privacy

Camera frames and Review export are processed only in this browser. Nothing is uploaded or sent to an external API. A file is created only when you explicitly save a Review clip. Runtime network access is blocked by CSP.

Browser requirements

A browser with camera access, WebCodecs, and requestVideoFrameCallback() is required. Missing capabilities are reported before the camera starts.

Current limitations

v0.4.0 adds local Review clip saving. MP4 is preferred when the browser can record it; otherwise WebM is used. Camera switching, Wake Lock, and fullscreen are not included yet.

Temporary data

The delay buffer exists only in memory. It is discarded when you stop, reload, or close the tab.
