# Practice Mirror v1.1.1

## Changes / 変更

- **Background and Wake Lock / バックグラウンドと画面点灯**: Make suspension state synchronous and prevent pending screen-lock requests from retaining a lock after Stop. Discard stale resume errors instead of moving a newly suspended session into an error state.
- **Review export / 見返し動画の保存**: Seek to the nearest preceding key frame when preparing the selected range. A short range near the end of a long history no longer decodes the entire history first.
- **Frame stepping / コマ送り**: Step to actual adjacent encoded frames, including when frame intervals are uneven.
- **Camera switching / カメラ切替**: Use a different enumerated device ID when desktop cameras do not expose facing mode or the facing-mode request selects the same camera.
- **UI consistency / 表示と取り消し**: Fix the Japanese camera-interruption message in Review; preserve guides added after Clear when restoring previously cleared guides using Undo.
- **Android canvas / Android映像**: Keep synchronized canvas presentation from v1.1.0 unchanged. The app owner reports that the previously observed line-like tearing is resolved.

## Validation / 検証

The PR adds Node regression tests for the lifecycle, Wake Lock, key-frame selection, irregular frame stepping, camera device targeting, Undo and translation keys. Existing browser tests cover synthetic camera/video encoding, Review looping and seekable WebM export, language and mobile layouts, and the no-runtime-network contract.

Run the PR's checks before merge. Physical-device testing is still recommended for repeated background/foreground transitions, front/rear and USB camera switching, and a 180-second Review with a short export at its end. CI is not evidence of physical iOS Safari or Android behavior.

## Release process / リリース

On merge to `main`, the main-only release workflow validates the exact commit before creating the `v1.1.1` tag and GitHub Release. The PR does not publish a release, and only the owner merges.
