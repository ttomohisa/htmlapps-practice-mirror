## Changes / 変更

- カメラ開始後にライブ映像で位置を合わせ、「練習を開始」で遅延表示へ進みます。
- 「見返す」は押す直前に表示していた場面で停止します。開始・終了の指定、区間ループ、選択区間だけのWebM保存に対応しました。
- スマホ画面を映像中心に整理しました。「見返す」は常時表示し、設定などの補助操作だけを自動で隠します。
- 映像の同期描画を有効にし、線状の表示崩れを起こし得る低遅延描画モードを無効にしました。
- 区間入力で丸めて表示した終了位置が範囲外と判定される問題を修正しました。

- Start with a live positioning preview, then begin delayed practice.
- Review pauses on the displayed frame. Select a range to loop or export as WebM.
- Phone controls are grouped around the video. Review remains visible while auxiliary tools can auto-hide.
- Synchronized canvas presentation replaces the low-latency mode that can introduce tearing.
- Editing a range boundary now preserves the exact timestamp of an unchanged rounded endpoint.

## Downloads / 配布ファイル

- `practice-mirror.html`: readable, self-contained HTML / 通常版。
- `practice-mirror.self-extract.html`: gzip self-extracting HTML / 自己展開版。
- `SHA256SUMS`: SHA-256 checksums for both HTML files / 両HTMLのチェックサム。

Camera access requires a compatible browser and permission. Local-file camera permission varies by OS/browser; use the HTTPS app if necessary. Video stays on the device. WebM exports use original speed and exclude audio, guides and mirroring.

カメラ利用には対応ブラウザと許可が必要です。ローカルファイルへのカメラ許可はOS・ブラウザによって異なるため、必要に応じてHTTPS版をご利用ください。映像は端末内で処理します。保存は元の速度のWebMで、音声・ガイド・左右反転は含みません。

## Verification limits / 未確認事項

Automated checks use Chromium with a synthetic camera and real WebCodecs/MediaRecorder. Physical iPhone/iPad Safari and Android cameras are not certified. Resolution of the reported Android line-noise symptom still requires confirmation on the reporting device.

自動検証は合成カメラと実際のWebCodecs／MediaRecorderを用いたChromiumで実施しています。iPhone／iPad SafariとAndroidの物理カメラは未確認です。報告端末で線状ノイズが解消したかは、実機での確認が必要です。
